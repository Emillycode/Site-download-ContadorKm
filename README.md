# 🌐 Contador Km — Landing Page & Distribuição

> Landing page oficial e responsiva para download direto e guia de instalação do APK do aplicativo **Contador Km**.

🔗 **Acesse o site online:** [contadorkm.onrender.com](https://contadorkm.onrender.com)

---

## 📌 Sobre a Página

Esta página estática foi desenvolvida para servir como o ponto central de distribuição do app Android **Contador Km**. Além de disponibilizar o download do instalador `.apk`, o site orienta o usuário em um passo a passo detalhado sobre como conceder permissões e instalar aplicativos fora da Google Play Store (sideloading seguro).

---

## 🎨 Características e UI

- **Design Dark & Automotivo:** Paleta de cores temática em tons escuros (`#0f1720`) com detalhes em azul e âmbar, simulando elementos de painel automotivo.
- **Velocímetro Animado em SVG:** Gauge dinâmico vetorial estilizado com efeitos de animação por CSS (`keyframes`).
- **100% Responsivo:** Layout adaptável para smartphones, tablets e desktops via CSS Grid e Flexbox.
- **Tipografia Personalizada:** Uso das fontes *Rajdhani* (títulos/display), *Inter* (corpo de texto) e *IBM Plex Mono* (elementos técnicos e numéricos).
- **Guia Passo a Passo Integrado:** Explicação clara do fluxo de liberação de "Fontes Desconhecidas" / "Instalar apps desconhecidos" no Android 7.0 ao Android 14+.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Marcação semântica e acessível.
- **CSS3 Puro:** Variáveis CSS (`:root`), Flexbox, CSS Grid, Animações com `@keyframes` e media queries.
- **SVG:** Ícones da marca, botão de download e animação do velocímetro.
- **Google Fonts:** Importação otimizada das famílias *Rajdhani*, *Inter* e *IBM Plex Mono*.
- **Hospedagem / Deploy:** [Render](https://render.com).
